## 系统能力与数据边界

1. **市场支持差异**：A 股、港股、美股具备较完整的行情、技术面、新闻与基本面链路；日股（`.T`）、韩股（`.KS` / `.KQ`）、台股（`.TW`）的部分高阶字段（如资金流、龙虎榜、板块强度）会按市场支持边界优雅降级为 `not_supported`，详情见 [6 大市场支持边界](/docs/features/market-support/)。
2. **免费数据源稳定性**：内置的 AkShare、Baostock、YFinance 等免费接口受上游限流、网络抖动与网页结构调整影响，可能出现临时缺口或降级，系统会记录质量状态并保留 `stale` 提示。
3. **LLM 不确定性**：大语言模型基于输入上下文生成研判总结，仍存在推理偏差或引用误差的可能；任何实际交易决策前请务必结合官方公告与个人独立判断。
4. **开源许可**：项目基于 **MIT License** 开源，二次开发或公开引用请保留仓库来源署名。
