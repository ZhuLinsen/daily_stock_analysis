## 本目录组织

`frozen_v1_5/` 将原始历史、增量、勘误、统一CSV、Python脚本、审计JSON/MD及SHA256清单**全部放在同一层**，便于原脚本无改动复跑：

```bash
cd research/growth_dividend_cycle/frozen_v1_5
python -m pip install exchange_calendars==4.13.1
python merge_audit_创业板指_中证红利_V1.5.py --workdir .
sha256sum 创业板指_中证红利_20100601-20261013_统一历史日线_V1.5.csv
```

**注意**：目前并未附带全A市场基准的完整行情，不能仅凭主表宣称已完成牛熊判定、领先滞后量化或交易信号验证。研究结果与数据冻结版本分目录保存。
