# 创业板指 / 中证红利统一日线数据包 V1.5

日期：2010-06-01—2026-10-13；3,972个交易日。

## 文件清单

- `统一历史日线_V1.5.csv`（完整中文长文件名）：研究用主表，两个指数开收盘（可选字段依照源数据提供能力）、每日收盘比值及来源追溯。
- `全量审计报告_V1.5.md`：实际审计与限制。
- `全量审计_V1.5.json`：机器可读审计结果与SHA256。
- `TDX交叉核验摘要_V1.5.json`：经GitHub连接跨源校验得到的历史重合区间统计。
- `merge_audit_创业板指_中证红利_V1.5.py`：**已实际运行**的独立合并/结构/日历/公式审计程序。
- 4份输入文件：两份原历史、V1.3增量、2013勘误，供离线复现。
- `SHA256_MANIFEST_V1.5.json`：包内文件哈希索引。

## 一键复现

将输入文件与脚本放在同一目录，安装 `exchange_calendars==4.13.1` 后运行：

```bash
python merge_audit_创业板指_中证红利_V1.5.py --workdir .
```

执行时不需要联网。已在隔离临时目录重新运行，并确认主CSV字节级 SHA256 完全相同。交叉TDX校验是另一个通过GitHub连接进行的独立核对环节，不由离线脚本联网重复。

## 数据字段

- `date`: 交易日（YYYY-MM-DD）；`cyb_open/high/low/close`: 创业板日线；`red_open/red_close`: 中证红利日线；`cyb_red_ratio`: 创业板收盘 / 中证红利收盘，Decimal四舍五入8位。
- `source_segment`: 历史或增量标识；`cyb_source_url`、`red_source_url`: 来源；`audit_note`: 勘误与人工确认。
- 历史3,924天没有创业板高低价；2026增量48天没有中证红利开盘价，均是源文件字段缺失、合法留空。两个指数**每日收盘价完整无空值**。

## 研究边界

这一份是**价格指数**比值日线，而非包含股息再投资的全收益比值；交易日结构与计算通过审计，并不等于3972天都获得指数公司官方逐日认证。2026-10-13为研究截止日期，后续交易日需增量更新。
