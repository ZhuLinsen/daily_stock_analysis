# 知识溯源政策

## 私有边界
允许记录的安全边界绝对路径仅为：
`/Volumes/future/projects/DSA Research OS/private-knowledge/xiaolonglong`

Phase 0 未读取该目录内的原文或子项，不导入、不索引、不联网采集，不从其他目录猜测来源。

## 最低元数据
每条未来可检索知识必须有：稳定 ID、原始出处、作者/发布者、发布日期、采集时间、授权依据、授权状态、敏感级别、内容哈希、版本、可用范围、保留期限和撤销状态。缺任一关键来源或授权字段不得用于结论。

## 数据流
原文留在 Git 外私有存储；索引也必须位于批准的私有数据目录。DSA 只接收最小必要、脱敏、带引用的检索结果。日志、异常、模型 trace、遥测和工具审计只记录不透明 ID、计数和状态，不记录原文、长摘要、查询中的敏感片段或向量。未经授权策略明确允许，私有原文、摘要或可还原片段不得发送给任何外部模型或第三方服务；授权缺失或不可验证时 fail-closed。

事实、观点和推断必须分开标记。推断必须引用其事实依据；观点必须保留作者与语境；任何类型都不得通过改写失去出处或授权状态。

## EvidenceRef 映射
公开来源可保存 URL 和短摘要；私有来源默认只暴露 `private://<opaque-id>`、日期、授权级别、哈希与安全摘要。面向未授权输出时，引用存在性可以保留，但内容必须隐藏并触发 abstain 或降级。EvidenceRef 必须记录来源、发布时间、抓取时间及其支持的 claim ID。

## 新鲜度
- 行情和事件：短期窗口最严格；
- 财报和管理层信息：按报告期与公告更新；
- 长期框架：可长期有效，但事实性输入仍需刷新；
- 超过策略阈值标记 stale，不得暗示为最新，不能支持“当前”事实。

## 测试、撤回与删除
测试只能用人工制作、不可逆脱敏的 fixture，不能从私有原文裁剪。授权撤回或原文删除时，必须按 provenance ID 删除原文引用、派生索引、向量、缓存、摘要和可还原派生结果，并使已生成证据失效；只保留不含内容的审计事件。路径访问必须先 canonicalize 后与批准根目录比较，拒绝 `..`、符号链接或挂载点造成的边界逃逸。
