# 自选股变化状态与下一步

Web 首页的自选股列表按单行聚合展示每只股票的当前处理状态。该能力用于把分散在图标、任务状态和详情入口里的信息收敛成可扫描的三段信号。

## 展示结构

每只自选股保留原有股票名、代码、最新分析时间、评分标签、删除按钮和点击打开最新详情能力，并新增三段紧凑信号：

| 信号 | 含义 | 当前来源 |
| --- | --- | --- |
| 变化 | 这只股票相对今日分析目标的变化状态 | `analyzedToday`、`latestItem`、今日状态查询结果 |
| 状态 | 当前是否已完成、待更新、确认中或任务运行中 | `analyzedToday`、`activeTask`、今日状态查询结果 |
| 下一步 | 用户下一步最应做什么 | 最新详情可用性、任务状态、今日状态 |

## 状态映射

| 场景 | 变化 | 状态 | 下一步 |
| --- | --- | --- | --- |
| 今日已分析且最新详情可打开 | 今日已更新 | 已完成 | 打开最新报告 |
| 有历史报告但今天未分析 | 有历史报告 | 待更新 | 运行今日分析 |
| 没有任何历史报告 | 等待首次分析 | 待更新 | 运行今日分析 |
| 正在确认今日状态 | 确认中 | 正在确认 | 等待状态确认 |
| 今日状态查询失败或未知 | 状态未知 | 待刷新 | 刷新确认 |
| 存在运行中或等待中的任务 | 保留原变化状态 | 任务状态 | 等待任务完成 |

## 交互边界

- 点击自选股主体仍只负责打开最新报告详情。
- 没有详情、详情查询中或详情状态未知时，继续展示原有提示。
- 删除按钮保持独立，不触发打开详情。
- 本次不新增单只股票的立即分析按钮，避免与现有批量分析入口产生重复提交语义。

## 后续扩展

- 接入实时涨跌幅后，`变化` 可从“是否有报告”升级为“价格变化 + 观点变化”。
- 接入 ResearchArtifact 后，`状态` 可展示 thesis 是否被触发或失效。
- 接入实体跳转模型后，`下一步` 可升级为可执行动作，如打开研报工作台、创建监控或加入组合。
