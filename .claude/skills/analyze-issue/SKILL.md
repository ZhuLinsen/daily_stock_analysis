# 分析 Issue

按仓库根目录 `AGENTS.md` 第 8 节同步基线。用 `gh issue view <n> --comments` 读取原帖和讨论，核对关联 PR 的真实合入状态及当前主干实现。

- **Bug** 记录版本、环境、触发步骤、预期和实际结果。追踪受影响的入口及用户后果，区分已复现、仅有用户报告、环境或第三方原因。
- **功能请求** 说明谁在什么场景遇到缺口、现有入口能覆盖什么、最小可验收范围是什么。已有 PR 只完成一期时，列明剩余范围。
- **处理建议** 给出成立程度、类型、优先级、难度和理由。说明可立即处理、排期、澄清或关闭的具体条件。涉及界面或报告展示时核对原帖截图和对应版本。

将基线、证据链接、未验证项及建议动作写入 `.claude/reviews/issues/issue-<number>.md`。需要对外回复时可先给评论稿。发评论、改标签、关闭或启动修复以用户授权为准。
